# ブログ記事の追加手順

このサイトのブログは、**記事のHTMLファイルを1つ追加して、`posts.json` に1件書き足すだけ**で更新できます。難しい作業はありません。下の手順に沿って進めてください。

## 手順

### 1. 記事ファイルを作る

- このフォルダ（`blog/`）にある既存の記事ファイル（例：`post-tonoko.html`）をコピーして、新しいファイル名に変えます。
  - ファイル名は半角英数字とハイフンで付けます（例：`post-urushi-care.html`）。
  - 先頭に `post-` を付けると管理が楽です。
- コピーしたファイルを開き、タイトル・日付・本文を新しい記事の内容に書き換えます。
  - 書き換える場所：`<title>`、記事見出し `<h1>`、日付とカテゴリの表示、本文の段落です。
  - サムネイル画像を変える場合は、記事冒頭の `<img src="../images/〜.jpg">` の部分を差し替えます。

### 2. サムネイル画像を用意する

- 画像ファイルを `images/` フォルダに入れます（JPG推奨、横長の写真がきれいに収まります）。

### 3. posts.json に1件追加する

- `blog/posts.json` を開き、`"posts"` の配列の**先頭**に、新しい記事の情報を追加します（先頭が一番新しい記事として表示されます）。
- 書き方は既存の項目をコピーして、中身を書き換えるのが確実です。

```json
{
  "slug": "post-urushi-care",
  "title": "記事のタイトルをここに書きます",
  "date": "2026-11-05",
  "category": "材料のはなし",
  "excerpt": "記事の要約を1〜2文で書きます。一覧ページに表示されます。",
  "thumb": "../images/新しい画像のファイル名.jpg"
}
```

| 項目 | 意味 | 注意点 |
|---|---|---|
| slug | 記事ファイル名から `.html` を除いたもの | ファイル名と必ず一致させる |
| title | 記事タイトル | 一覧と記事ページで同じにする |
| date | 公開日 | `2026-11-05` の形式で書く |
| category | 分類名 | 既存の分類に合わせると統一感が出ます |
| excerpt | 要約文 | 1〜2文、80〜120字程度が目安 |
| thumb | サムネイル画像のパス | `../images/` から始める |

- 項目の間にはカンマ `,` が必要です。最後の項目の後にはカンマを付けません。
- 文字を囲むダブルクォート `"` を消さないようにしてください。

### 4. 公開する

- 追加したファイル（記事HTML、画像、posts.json）を GitHub に反映（コミット＆プッシュ）すると公開されます。
- 反映の方法はリポジトリの運用担当者に確認してください。

## うまく表示されないとき

- **一覧に記事が出ない**：posts.json のカンマやクォートの付け忘れがほとんどです。既存の項目と見比べてください。
- **画像が表示されない**：thumb のパスと、`images/` 内の実際のファイル名が一致しているか確認してください。
- **ローカルで確認したい場合**：ファイルを直接開くと一覧が読み込めないことがあります。簡易サーバー経由での確認が確実です（例：サイトのフォルダで `python3 -m http.server` を実行し、`http://localhost:8000/blog/` にアクセス）。
